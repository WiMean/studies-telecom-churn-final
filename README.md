# Прогнозирование оттока клиентов оператора связи (финальный проект)

**Задача.** Оператор связи «ТелеДом» борется с оттоком: клиентам, которые планируют уйти, предлагают промокоды и специальные условия. Нужна модель, предсказывающая разрыв договора. ROC-AUC не ниже 0,85.

**Что сделано.** Загрузка четырёх связанных таблиц из PostgreSQL, предобработка и исследовательский анализ, feature engineering, отбор признаков, обучение и сравнение моделей (логистическая регрессия, CatBoost, LightGBM, XGBoost, нейронная сеть), подбор гиперпараметров (Optuna), интерпретация результатов (SHAP).

**Стек.** Python, pandas, scikit-learn, CatBoost, LightGBM, XGBoost, Optuna, SHAP, SQLAlchemy

**Результат.** ROC-AUC 0,86 на тестовой выборке, accuracy 0,78; до 0,95 на кросс-валидации
